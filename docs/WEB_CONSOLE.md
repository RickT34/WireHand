# 网页控制台与脚本库

[返回文档导航](README.md)

先按照 [Docker 桌面](DOCKER_DESKTOP.md) 或 [ROCK 5B+](rock5b-plus/README.md) 指南启动服务并登录。
页面只有接管和非接管两种模式；右上角可以打开 SDK 文档。

## 接管与录制

1. 点击“接管控制”，当前浏览器独占键鼠输入。已有的脚本任务会先停止。
2. 输入脚本名称，点击“开始录制”，在设备画面上操作。
3. 点击“停止并生成脚本”。脚本、录制数据和目标图片自动保存在服务器并出现在脚本库。
4. 点击“结束接管”，即可运行脚本。连接中断会结束接管；录制中断的脚本保留用于检查，但不能直接运行。

接管时，所有 MCP 工具调用返回错误，包括截图、观察和状态查询。结束接管后恢复。
脚本执行时也独占自动输入，避免其他自动化会话插入操作。

录制只在鼠标按下时截图并提取附近元素作为 target，拖动沿用按下时的目标。键盘、移动和滚轮不生成 target，保留位置与操作间隔。

## 脚本管理与执行

- 名称用于网页显示，也作为下载的 ZIP 文件名。可在脚本列表中重命名或删除。
- 选择重复次数（1–100000），或勾选“无限重复”，再点击对应脚本的“运行”。
- 同一设备同时运行一个脚本。每轮在新的 Python 进程中执行，工作目录为脚本所在目录。
- 页面显示已经完成的轮次、当前轮次、执行状态和最近 32 KiB 的输出。
- 点击“停止执行”终止任务并释放按键；脚本异常时停止后续重复并保留错误日志。
- 关闭浏览器不会停止服务器任务。服务器正常退出会停止任务；服务重启后不自动续跑。
- Linux 上运行器异常退出会终止直接脚本进程；重启时恢复遗留的输入状态。

实际执行入口是 **`replay.py`**。网页不会重新生成它，也不会只执行 recording.json 而忽略修改。
`Computer.replay()` / `Recording.replay()` 则专门执行 recording.json 中的语义步骤。

## 下载、修改与重新上传

1. 下载，例如 `每日整理.zip`。
2. 解压后修改 `replay.py`，可添加 Python 辅助模块和数据文件。
3. 重新打包，保持 `replay.py` 与资源的相对路径。ZIP 内可以有一层父目录，也可以直接放文件。
4. 上传相同文件名。页面提示是否替换，确认后使用校验通过的新版本替换旧版本。

同名按 Unicode NFC 规范化后的名称比较，忽略大小写。替换还校验版本，防止覆盖确认之后发生的新修改。
正在执行或正在录制的脚本必须先停止，才能替换、重命名或删除。
ZIP 大小、解压总量各限制 64 MiB，最多 1000 个文件，入口 Python 文件最多 2 MiB。
上传会检查 Python 语法、压缩包路径、符号链接和录制资源；上传本身不执行代码。

脚本以服务用户身份在服务器运行，拥有该用户的文件和进程权限；它不是受限脚本沙箱。
只有已登录、同源请求可以上传和执行。运行子进程不会继承 `KVM_TOKEN`。

## 本地存储

CLI 的默认目录是 `~/.local/share/kvm-mcp/recordings`，可以用 `KVM_RECORDINGS` 指定持久目录。
Docker 桌面使用 `/var/lib/kvm-mcp/recordings`，现有 Compose 已将该目录持久化。

```text
recordings/
  <内部 ID>/
    script.json       # 服务维护的名称、版本和创建时间
    replay.py         # 实际执行入口，可修改
    recording.json    # 录制的步骤与目标；手写脚本可省略
    assets/           # 模板图片
    ...               # 用户添加的辅助文件
```

内部目录 ID 不随名称变化。下载包不包含服务器元数据，重新上传后以 ZIP 文件名作为脚本名。
脚本文件持久保存；运行状态与最近日志只保留在当前服务进程中。

## 自动生成 SDK 文档

访问 `/docs/`。服务首次访问时在独立进程中调用 **pdoc**，从当前 SDK 的签名和 docstring
生成静态 HTML，并在本次服务生命周期内缓存。页面有搜索、参数说明、示例和模块链接；无需访问外部文档服务。
更新代码后重启网页服务即可生成新版本。

也可以离线导出：

```bash
uv sync --frozen
uv run wirehand-docs --output artifacts/sdk-docs
```

维护接口说明时修改对应函数或类的 docstring，无需手工同步网页参数列表。

实现分层见 [架构说明](ARCHITECTURE.md)，开发和测试命令见 [贡献指南](../CONTRIBUTING.md)。
