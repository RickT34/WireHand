连接与操作说明

请按照所用平台的接线说明，连接被控设备的视频输出与键鼠输入接口。

手动接管时 MCP 输入暂停。切换标签或窗口会释放按键；连接断开后自动结束接管并恢复 MCP；无响应连接最多约 7 秒后释放。

建议单屏或复制模式。键盘按物理位置映射，中文需使用目标电脑的输入法。浏览器保留的组合键可通过上方菜单发送。
